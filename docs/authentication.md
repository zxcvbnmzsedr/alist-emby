# 认证与访问边界

## 普通 API 模式

用户名和密码由服务转交 AList 的 `/api/auth/login`，随后通过 `/api/me` 检查管理员身份。密码不写入数据库。客户端收到独立随机 Token，SQLite 以其 SHA-256 为会话索引，会话期限为 30 天。

此模式在会话表内保存上游 AList 登录 Token；状态文件含认证材料，必须私有保存。AList Token 可能先于兼容会话到期，此时需重新登录。服务每隔最多 15 秒再次核验上游身份；普通模式的上游身份撤销存在此缓存窗口。

只有管理员可登录，因为片库索引没有逐用户目录过滤。`Users/{uid}` 必须与当前会话用户一致，客户端取得的是播放权限声明，不取得管理或删除内容权限。

## 可选同机模式

同时配置 `ALIST_DATABASE` 与 `ALIST_CONFIG` 后，服务只读访问 AList 的账号表、管理 API Token 和 JWT 配置。依赖的表为 `x_users`、`x_setting_items`，字段包含角色、禁用状态、密码摘要、密码时间戳、salt 和 OTP 配置；这个依赖需要随 AList 升级验证。

该模式仅支持与管理 API Token 对应的管理员。每次请求比较账号与签名材料摘要，并每隔最多 15 秒向 AList 复核身份。改密码、改 2FA、账号删除/禁用/降权、JWT 密钥或管理 Token 轮换会使兼容会话失效。

同机模式会话不持久化管理 API Token，不因初次登录 JWT 自然到期而失效。读取 AList 配置与数据库意味着服务具有高权限认证材料的读取能力，应将其部署在可信主机并严格限制文件访问。

从普通模式切换到同机模式时，会话可迁移：仅允许上游仍有效，或明确报 `token is expired` 且旧 JWT 签名、账号、密码时间戳均通过校验的会话。明确撤销或签名错误不能迁移。迁移后的会话不能在关闭同机模式后降级运行；无需迁移的独立新部署可直接选定一种模式。

## 媒体与图片签名

- `PlaybackInfo` 先检查清单文件权限；HLS 入口仍需兼容会话。
- 返回清单中的 AList 地址是能力链接，其签名期限和撤销由 AList 决定。兼容会话退出不会自动撤销已经取得的密钥或分片链接。
- 不发送会话 Header 的客户端图片加载器可以使用 `ImageTags` 中的 HMAC；只授权特定影片的一种图片，不能用于访问片库或播放接口。
- 图片签名基于影片 ID、图片类型和图片路径，退出不立即撤销；改变图片路径或轮换状态库中的图片签名私钥会改变签名。
- SQLite 目录为 0700、数据库为 0600。备份状态库会同时备份会话和签名私钥，应按私有凭据管理。

## 日志和部署

HTTP 默认访问日志关闭，应用日志记录方法、路径、状态、返回条数、白名单过滤参数及清理后的 User-Agent，不记录 query Token、密码或搜索文本。Nginx 模板关闭兼容路由访问日志；其他代理、AList 文件路由日志也可能记录签名地址，请检查自己的实际日志配置。

由 HTTPS 代理提供客户端入口；兼容服务默认只监听 loopback。`X-Real-IP` 用于登录限速，代理必须覆盖此 Header，并使客户端只能经由该代理访问服务。登录限速为每来源地址每分钟最多 10 次尝试。

同一站点的 `/api/`、`/d/`、`/p/` 由 AList 负责；不要额外把私有 `/m3u8` 目录映射成不鉴权的静态目录。Emby 客户端的索引和图片通过兼容服务提供；网页的 catalog / covers 由配套 Lua 网关鉴权。
